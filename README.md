# Soporte Digital VER

Plataforma web (PHP/MySQL) para gestionar solicitudes de soporte técnico de familias y pequeños negocios de la región de Veracruz.

## Problemática
Soporte Digital VER es un sistema web de gestión para centralizar solicitudes de soporte técnico, clientes, técnicos y agenda de servicios. Resuelve el problema de llevar el control de forma manual o informal mediante WhatsApp y papel —lo que hoy provoca pérdida de seguimiento, tiempos de espera indefinidos y desorganización operativa para los usuarios y técnicos

## Tecnología
PHP, MySQL, HTML/CSS/JS.

Una historia pasa a **Done** cuando:
